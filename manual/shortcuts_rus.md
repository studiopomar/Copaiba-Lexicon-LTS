# Справочник горячих клавиш — Copaiba Lexikon `e-LTS(se)`

Полный список клавиатурных комбинаций и действий мыши в **Copaiba Lexikon**.

---

## Файлы и Проекты

| Действие | Сочетание | Описание |
| :--- | :--- | :--- |
| **Открыть войсбанк...** | `Ctrl + O` | Открывает папку войсбанка и считывает `oto.ini` |
| **Открыть проект...** | `Ctrl + Shift + O` | Открывает сохраненный файл проекта (`.copaiba`) |
| **Сохранить (oto.ini)** | `Ctrl + S` | Сохраняет изменения в `oto.ini` |
| **Сохранить проект** | `Ctrl + Shift + P` | Сохраняет текущее состояние проекта |
| **Сохранить как...** | `Ctrl + Shift + S` | Сохраняет `oto.ini` под новым именем |
| **Перезагрузить всё** | `Ctrl + F5` | Перезагружает файлы и конфигурацию с диска |
| **Открыть папку в проводнике** | `Ctrl + P` | Открывает системный файловый менеджер в папке войсбанка |
| **Общие настройки** | `Ctrl + ,` | Открывает окно глобальных параметров |

---

## Маркеры волновой формы

> [!NOTE]
> Буквенные клавиши выставляют соответствующий маркер строго по текущей позиции курсора мыши на волне.

| Клавиша | Маркер | Цвет | Назначение |
| :---: | :--- | :---: | :--- |
| **`Q`** | **Offset** | Синий | Точка начала полезного звука |
| **`W`** | **Overlap** | Зеленый | Граница зоны кроссфейда |
| **`E`** | **Preutterance** | Красный | Точка ритмической доли / атака гласной |
| **`R`** | **Consonant** | Розовый | Граница фиксированной согласной |
| **`T`** | **Cutoff** | Синий | Точка конечной обрезки |

## Навигация и Масштаб

| Действие | Команда | Описание |
| :--- | :--- | :--- |
| **Масштаб времени (X)** | `Ctrl + Scroll` | Увеличение/уменьшение масштаба по времени |
| **Масштаб амплитуды (Y)** | `Alt + Scroll` | Увеличение/уменьшение усиления волны |
| **Смещение (Панорама)** | `Shift + Scroll` | Сдвиг волновой формы влево/вправо |
| **Перетаскивание маркера** | `ЛКМ + Drag` | Прямое перемещение линий параметров мышью |
| **Переключение алиасов** | `Стрелки Вверх / Вниз` | Выбор предыдущего или следующего алиаса |
| **Смена колесом мыши** | `Scroll мыши` | Вращение колеса над волной переключает алиасы |
| **Воспроизвести сектор** | `ЛКМ` | Воспроизведение нажатого сектора волны |
| **Воспроизведение от точки** | `Alt + Клик` | Воспроизведение начиная с точки клика |

## Воспроизведение и Синтез

| Действие | Сочетание | Описание |
| :--- | :--- | :--- |
| **Воспроизвести сегмент** | `Пробел` | Воспроизведение области от Offset до Cutoff |
| **Воспроизвести весь файл** | `Shift + Пробел` | Воспроизведение исходного `.wav` файла целиком |
| **Тест синтеза** | `Ctrl + Shift + Пробел` | Рендеринг и прослушивание через внешний ресемплер |

## Быстрые Пресеты

| Сочетание | Пресет | Назначение |
| :--- | :--- | :--- |
| **`Ctrl + 1`** | **CV** | Стандартный слог Согласная + Гласная |
| **`Ctrl + 2`** | **VCV** | Слитные переходы Гласная-Согласная-Гласная |
| **`Ctrl + 3`** | **VV** | Переходы между гласными |
| **`Ctrl + 4`** | **VC** | Кода слога / конечная согласная |
| **`Ctrl + 5`** | **-V** | Начальная изолированная гласная |
